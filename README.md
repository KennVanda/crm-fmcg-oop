# CRM Analytics for FMCG Companies

Program Python berbasis OOP yang mencatat penjualan produk FMCG dari
perusahaan ke pelanggan, lalu menganalisis pelanggan loyal, top-k
pelanggan, produk favorit, churn, segmentasi RFM, dan rekomendasi produk.

Tugas Besar SI-102 Dasar Pemrograman I, Sistem Informasi ITHB (2026).
Kelompok: Kenneth Mahinda Vanda (1226005) & Jovanka Vesya Ndearly (1225020).

## Fitur
- 18 class: abstraction, encapsulation, inheritance, polymorphism
- Pelanggan loyal berdasarkan share of wallet
- Transaksi multi-produk, ubah/hapus data, simpan/muat CSV
- 20 unit test otomatis

## Cara menjalankan
Buka CRM_FMCG.ipynb di Google Colab, jalankan sel 1-5.
Atau: python crm_fmcg.py  |  python crm_fmcg.py --menu
